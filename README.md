# CodeAlpha_AIChatbot
## Project Overview
The Artificial Intelligence Chatbot is a Java-based application developed as part of my CodeAlpha Java Programming Internship – Task 3.

The main purpose of this project is to provide interactive communication between the user and the chatbot. It uses rule-based responses to answer frequently asked questions about Java, Artificial Intelligence, Natural Language Processing (NLP), and Machine Learning.

## Features
- Interactive communication between the user and the chatbot.
- Provides rule-based answers to user questions.
- Responds to frequently asked questions (FAQs).
- Uses basic text-processing techniques to identify user queries.
- Provides predefined responses for greetings, help requests, and common questions.
- Includes a graphical user interface (GUI) using Java Swing.
- Supports real-time interaction through a text field and send button.

## Technologies Used
- Java
- Java Swing
- AWT
- HashMap / LinkedHashMap for storing FAQ responses (if used in the source code)
- Rule-Based Chatbot Logic
- Basic Natural Language Processing (NLP) Techniques

## How It Works
1. The chatbot starts with a welcome message.
2. The user enters a question in the chat interface.
3. The program processes the input and checks for matching keywords or predefined questions.
4. The chatbot selects an appropriate response based on its rules.
5. The response is displayed in the chat window.
6. The user can continue the conversation in real time.

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project in Visual Studio Code or another Java IDE.
4. Compile the Java source file using the appropriate filename. For example:

   `javac Chatbot.java`

5. Run the program using the appropriate main class. For example:

   `java Chatbot`

**Note:** Replace `Chatbot.java` and `Chatbot` with the actual filename and class name in your project. If your class extends `JFrame`, make sure the main method starts the GUI.
